NOVA FINANCE – Linux Security Investigation Lab

Introduction

This project documents my practical Linux Security Investigation Lab. The exercise involved investigating file permissions, ownership, user accounts, and group memberships in a simulated company environment called NOVA FINANCE.

Objectives

* Understand Linux file permissions.
* Investigate file and directory ownership.
* Identify user and group memberships.
* Check access permissions on sensitive files.
* Identify potential security risks in a Linux system.

Tools and Commands Used

During this lab, I practised using the following Linux commands:

* ls -l – To view file permissions, ownership, and groups.
* stat – To display detailed file information.
* id – To check user identity and group memberships.
* groups – To display the groups a user belongs to.
* find – To locate files and directories.
* getfacl – To examine file access control lists.

Investigation Tasks

Ticket 1: Payroll File Security
Investigated who could access the company’s payroll file.

Ticket 2: Personnel File Security
Examined file permissions to understand who could modify HR personnel records.

Ticket 3: Database Backup Security
Checked permissions on the database backup file to identify possible security risks.

Ticket 4: Intern Access Control
Investigated the group memberships assigned to an intern’s account.

Ticket 5: Former Employee Account
Checked the group memberships of a former employee to identify any unnecessary access.

Ticket 6: Shared Announcement File
Investigated file ownership and write permissions on the company’s shared announcement document.

Skills Gained

* Linux command-line navigation.
* File and directory management.
* Linux permissions and ownership.
* User and group administration.
* Basic cybersecurity investigation.
* Access control and security awareness.

Conclusion

This practical lab improved my understanding of Linux system administration and basic cybersecurity. I gained hands-on experience using Linux commands to investigate file permissions, user access, ownership, and potential security vulnerabilty
